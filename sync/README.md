# Sync — Flutter MVP

A location-based app for real-time human connection. Pulse a vibe, see who's
nearby, sync for 30 minutes, then everything self-destructs.

This directory is the Flutter + Firebase MVP. The repo's other directories
belong to an unrelated project — work on Sync stays inside `sync/`.

## Stack

- **Flutter** (Dart 3.3+) with Material 3
- **google_maps_flutter** + custom dark style + glowing pulse markers
- **geolocator** + **geocoding** for tracking and reverse-geocoding the city
- **firebase_core / cloud_firestore / firebase_auth** (anonymous sign-in)
- **Cloud Functions (Node 20)** for the 30-minute self-destruct sweeper

## Firestore schema

### `syncs/{syncId}`

| field             | type        | notes                                                      |
|-------------------|-------------|------------------------------------------------------------|
| `userId`          | `string`    | Auth UID of the creator                                    |
| `category`        | `string`    | One of `move` \| `play` \| `talk` \| `help`                 |
| `location`        | `geopoint`  | (lat, lng)                                                 |
| `geoBucket`       | `string`    | Coarse `floor(lat*100)_floor(lng*100)` cell, ~1.1 km grid  |
| `createdAt`       | `timestamp` | Server-stamped at creation                                 |
| `expiresAt`       | `timestamp` | `createdAt + 30 min` (server-authoritative)                |
| `active`          | `bool`      | Mirrors lifecycle; flipped by sweeper before deletion       |
| `serverStampedAt` | `timestamp` | When the Cloud Function re-stamped the doc                 |

### `syncs/{syncId}/messages/{messageId}` (subcollection)

| field       | type        | notes                                |
|-------------|-------------|--------------------------------------|
| `userId`    | `string`    | Auth UID of the sender               |
| `text`      | `string`    | ≤ 500 chars (enforced by rules)      |
| `createdAt` | `timestamp` | Server-stamped on write              |

The whole subcollection is wiped together with the parent at expiry.

## The 30-minute rule

Three layers enforce it:

1. **Client query** — `FirestoreService.liveMarkers()` filters
   `createdAt > now - 30min` and additionally drops anything past `expiresAt`
   in case a stale snapshot leaks through.
2. **Security rules** — `firestore.rules` only allows reads when
   `createdAt` is within 30 minutes of the current request time. Clients
   cannot update `expiresAt`.
3. **Cloud Function `sweepExpiredSyncs`** — runs every minute, recursively
   deletes the `messages` subcollection in batches, then deletes the sync
   document itself, removing both the chat and the map marker.

## Quick start

```bash
cd sync
flutter pub get

# Firebase
cd functions && npm install && cd ..
firebase deploy --only firestore:rules,functions
flutter run
```

You will need:

- An iOS/Android Google Maps API key wired into the platform manifests
  (`AndroidManifest.xml`, `Info.plist`) — outside the scope of this MVP scaffold.
- A `firebase_options.dart` generated by `flutterfire configure`.
- Location permissions configured in the platform manifests.
