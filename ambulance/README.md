# מערכת EMS / מד"א מתקדמת — FiveM (ESX + ox_lib)

מערכת תפקיד מד"א/אמבולנס מאופטמת לשרת FiveM, כתובה כולה ב-Lua,
תואמת ל-**ESX** המודרני (`exports['es_extended']:getSharedObject()`)
ומשתמשת ב-**ox_lib** לתפריטי הקשר ולפסי התקדמות.

## תכונות עיקריות

### 1. מערכת מוות / עילפון מתקדמת
- ביטול מנהל ההחייאה הדיפולטי של GTA V.
- מצב "עילפון" (Knockout): בריאות מלאה, אלמוות, אנימציית שכיבה (`dead`/`dead_a`) בלולאה.
- חסימת תנועה, ירי ושליטה ברכב.
- טקסט על המסך: `אתה מעולף. לחץ [G] לאות מצוקה | לחץ [E] לקביעת מוות ושיגור`.
- **[G]** — אות מצוקה לכל יחידות מד"א המחוברות (Cooldown של 60 שניות + בליפ מהבהב).
- **[E]** — בקשת קביעת מוות. השרת שולף זמן/תאריך מדויקים (`os.date`),
  משדר הודעה גלובלית, מחיה את השחקן, מאפס מזומן ל-0 ומשגר לבית החולים.

### 2. בדיקת מדדים דינמית + תצוגת HUD אדומה
- פקודה `/checkvital` (קיצור **H**) ותפריט טיפול (קיצור **F6**) — לעובדי מד"א בלבד.
- פס התקדמות מעגלי של ox_lib (4 שניות): "בודק מדדים רפואיים...".
- מדדים מחושבים בשרת לפי מצב המטופל:
  - **יציב:** דופק 70–95, לחץ דם ~120/80, חמצן 96–100%.
  - **קריטי (עילפון):** דופק 110–140, לחץ דם ~90/60, חמצן 80–90%.
- **התוצאה מוצגת בצבע אדום בפינה השמאלית-התחתונה של המסך** למשך 15 שניות.

### 2א. תפריט רדיאלי (עיגול) — מקש F3
תפריט עגול (radial) של ox_lib. לחיצה על אופציה פותחת את המשך האפשרויות **בתוך אותו עיגול**:
- **בדיקת מדדים** — הצגת HUD המדדים.
- **טיפול בפצעים** → נפתח תת-עיגול: **פצעים קלים** (שחזור חלקי, 6ש') / **פצעים קשים** (ייצוב + שחזור מלא, 12ש').
- **החייאה** — החזרת מטופל מחוסר הכרה (10ש').
- **קשר / תגבור** — שליחת מיקומך ליחידות מד"א נוספות.
- **קביעת מוות** — עם דיאלוג אישור; משדר הודעה גלובלית ומשגר את המטופל לבית החולים.

> האופציות מופיעות בעיגול רק כאשר השחקן בתפקיד `ambulance` (נוספות/מוסרות אוטומטית לפי המשרה).
> מכיוון ש-ox_lib פותח את העיגול דרך הפקודה `+ox_lib-radial`, מקש F3 פשוט מפעיל אותה.

### 3. אזורי אינטראקציה (ox_lib Context Menus)
זמינים רק לבעלי המשרה `ambulance`:
- **חדר הלבשה** — מדים לפי דרגה (0 מתלמד, 1 פראמדיק, 2 רופא, 3 מנהל) + חזרה לאזרחי.
- **בית מרקחת** — רכישת ציוד (ערכת החייאה $150, תחבושת $30, דפיברילטור $500) מהמזומן.
- **מוסך רכבים** — הוצאת רכבי חירום לפי דרגה (דרגה 0 אמבולנס, דרגה 2 רכב מהיר, דרגה 3 מסוק).
- **נקודת החזרה** — עיגול אדום על הקרקע; כניסה ברכב חירום + [E] מוחקת אותו בבטחה.

### 4. אופטימיזציה
- כל ה-`CreateThread` משתמשים ב-`Wait` דינמי. רחוק מהסמנים = שינה של 1500ms (Resmon ≈ 0.00ms).

## התקנה
1. העתק את התיקייה לתוך `resources/[jobs]/ambulance`.
2. ודא ש-`es_extended` ו-`ox_lib` עולים **לפני** המשאב הזה.
3. הוסף ל-`server.cfg`:
   ```
   ensure ambulance
   ```
4. צור את המשרה `ambulance` במסד הנתונים עם דרגות 0–3.
5. התאם קואורדינטות, מדים ומחירים ב-`config.lua`.

## קבצים
| קובץ | תפקיד |
|------|-------|
| `fxmanifest.lua` | מניפסט המשאב והתלויות |

| `client/main.lua` | אתחול, לולאת סמנים מאופטמת, החזרת רכבים |
| `client/death.lua` | מצב עילפון, אות מצוקה, קביעת מוות |
| `client/menus.lua` | תפריטי ox_lib + פקודת `/checkvital` |
| `server/main.lua` | שעון שרת, מדדים, רכישות, החייאה, אנטי-צ'יט |
