# Modsmith — engineering brief (read before contributing)

Modsmith is a browser-based FiveM asset workshop: creators upload models/textures, edit them in browser tools (Three.js / React Three Fiber), send heavy conversions to BullMQ workers, and download complete FiveM resources. Credits (ledger-based), Stripe billing, Discord linking, referrals, a public showcase and a "Server Hub" (logs/screenshots/phone media for FiveM servers) round out the product. This is an original product; never reference or copy any other company's branding.

## Repo layout (pnpm workspace, root = `modsmith/`)
- `apps/web` — Next.js 15 (App Router, React 19, TS, Tailwind v4). `src/app` routes, `src/components/ui` (shadcn-style kit: button, input, label, form, card, badge, dialog, dropdown-menu, select, switch, checkbox, tabs, tooltip, progress, slider, avatar, misc (Spinner, Skeleton, EmptyState, Alert, PageHeader, Stat, Kbd, Pagination), toast), `src/components/shared` (UploadZone, JobProgress), `src/hooks` (useMe, useJob, useUpload), `src/lib` (utils: cn/formatBytes/formatDate/timeAgo/formatCredits/formatMoney/slugify; api-client: `api<T>(path, {json})` adds CSRF header; zip), `src/server` (session.ts: getSession/getCurrentUser/createSession/destroySession; api.ts: apiRoute wrapper; auth.ts).
- `apps/worker` — BullMQ workers (tsx). Processors implement `AssetProcessor` from `@modsmith/core`.
- `packages/core` — `TOOLS` registry (`getTool(slug)`, `TOOL_CATEGORIES`), zod schemas (`TOOL_CONFIG_SCHEMAS`, auth/hub/admin schemas), `ok/fail/ApiFailure/ErrorCodes`, `AssetProcessor` interface, `JOB_STAGES`, `LIMITS`, `CREDITS`, `BRAND`.
- `packages/db` — Prisma schema/client (`import { prisma } from "@modsmith/db"`). BigInt fields: sizeBytes, hubStorageBytes.
- `packages/services` — server-side services shared by web + worker: env(), logger, redis(), crypto, rateLimit, audit(), settings (getSetting/isFlagEnabled/getEffectiveTools), storage() provider (S3/local; signedGetUrl/putObject/getObject/deleteObject), credits (applyLedgerEntry/grantOnce), email (sendEmail + templates), discord, notify(), queue (getQueue/enqueue/QUEUE_NAMES), jobs (createJob/estimateJob/recordJobProgress/completeJob/failJob/cancelJob/retryJob/publishJobEvent), billing (Stripe), hub (tokens/ingest/media), uploads (validation/sniffing).
- `packages/hub-resource/msmhub` — FiveM Lua resource.

## API contract
All JSON endpoints live under `/api/v1/*` and return `{ success, data, error }`. Use `apiRoute({auth, roles, body, query, rateLimit}, handler)` from `@/server/api`. Mutations from the browser must go through `api()` in `src/lib/api-client.ts` (it sends the `x-csrf-token` header). Server components read data via Prisma directly (`getCurrentUser()` for auth) — never fetch our own API from server components.

Key endpoints: auth (`/auth/register|login|logout|forgot|reset|verify|verify/resend|me|sessions|discord`), `/users/me` (PATCH profile, DELETE account) + `/users/me/notifications|privacy|password`, `/tools`, `/tools/:slug/estimate` (POST {uploadIds, config}), `/uploads` (POST init → signed PUT/multipart; `/uploads/:id/complete`), `/jobs` (POST {toolSlug, uploadIds, config, name, creationId?, rightsConfirmed?}; GET list), `/jobs/:id`, `/jobs/:id/cancel|download|events(SSE)`, `/creations` (+ `:id`, `duplicate`, `reexport`, `publish`, `unpublish`, `download`, `versions`), `/credits` (+`/transactions`, `/packs`), `/billing` (+ `checkout/pack`, `checkout/subscription`, `portal`, `plans`, `subscriptions/:id/cancel|resume`, `webhook`), `/showcase` (+ `:slug`, `like`, `view`, `report`, `download`), `/reviews`, `/referrals` (+`/click`), `/server-hub/*` (projects, tokens, logs, media, overview, resource), `/notifications` (+`/read`, `/stream` SSE), `/admin/*` (overview, health, users, credits/adjust, jobs(+retry/refund), creations, tools, packs, plans, partners, guides, guide-categories, changelog, reviews, showcase, reports, flags, audit, settings, hub, stripe), `/external/sketchfab/search|import`. Ingestion: `POST /hub-ingest/v1/logs`, `POST /hub-ingest/v1/media/reservations`, `PUT /hub-ingest/v1/media/reservations/:id?t=`, `POST /hub-ingest/v1/screenshots`.

## Conventions
- Dark-first, high-contrast, restrained orange accent (`text-accent`, `bg-accent`, tokens: bg, bg-elevated, bg-muted, bg-subtle, border, border-strong, fg, fg-muted, fg-subtle, success, warning, danger, info). Compact cards, subtle borders, clear status badges (`StatusBadge`), excellent empty states (`EmptyState`), keyboard accessible, reduced-motion safe, responsive down to 375px.
- Client components: `"use client"` at top; use `useToast()` for feedback; handle loading/error/empty states explicitly.
- Never trust the client for credits, job status, or ownership. Never expose storage keys/URLs beyond short signed URLs. Every DB read in a page must be scoped to the current user unless the data is public.
- Type-check with `pnpm --filter @modsmith/web exec tsc --noEmit` (do NOT run `next build` in parallel with other agents). Lint with `pnpm --filter @modsmith/web lint`.
- Only touch files inside your assigned ownership; if you need a shared change, make it minimal and additive.
- Do not add dependencies unless truly needed; if you do, pin an exact version and run `pnpm install` from the repo root.
